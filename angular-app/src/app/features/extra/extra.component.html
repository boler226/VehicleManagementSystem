Одержати відомості про вантажоперевезення, виконані вказаним автомобілем протягом вказаного періоду часу. Одержати відомості про наявність гаражів загалом та для кожної категорії транспорту. Одержати дані про автопарк підприємства, дані про пробіг автотранспорту певної категорії або конкретної автомашини за вказаний день, місяць, рік. Одержати дані про кількість використаних для ремонту вказаних вузлів та агрегатів для транспорту вказаної категорії. Одержати дані про розподіл пасажирського автотранспорту за маршрутами. Одержати інформацію про кількість ремонтів та їх вартість для автотранспорту певної категорії, окремої марки автотранспорту або зазначеного автомобіля протягом вказаного періоду. Одержати інформацію про отриману та списану автотехніку протягом вказаного періоду часу. Одержати інформацію про роботи, виконані вказаним фахівцем протягом вказаного періоду загалом та стосовно конкретного автомобіля. Одержати перелік та загальну кількість водіїв загалом та для вказаних моделей авто. Одержати список підлеглих вказаного бригадира, майста, керівника цеху.
